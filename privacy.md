# Privacy — CardOps trasferimento PC

Ultimo aggiornamento: 13 ottobre 2026.

CardOps trasferimento PC è un'utilità personale eseguita sui computer del
titolare dell'account Google. Non dispone di un server che raccolga i dati
degli utenti.

## Accesso e utilizzo dei dati Google

L'app richiede il permesso `drive.file`, che consente di gestire i file creati
dall'app o esplicitamente selezionati per essa. Usa Google Drive per creare,
leggere e verificare backup cifrati e informazioni cifrate sui passaggi tra PC.
Non richiede accesso a Gmail, contatti, calendario o all'intero contenuto di Drive.

## Conservazione e condivisione

Database e fotografie sono cifrati sul PC prima dell'invio all'account Drive
scelto dall'utente. I token OAuth e la chiave di cifratura sono conservati
localmente; non sono pubblicati nel repository del codice. L'utente deve
custodire separatamente il pacchetto che permette di collegare il secondo PC.
Il backup non include i token delle integrazioni del gestionale.

L'app non vende dati e non li utilizza per pubblicità, profilazione o
addestramento di modelli di intelligenza artificiale. Non condivide i backup
con altri utenti. Google tratta i dati caricati secondo le condizioni del suo
servizio; il contenuto dei backup resta cifrato.

## Controllo dell'utente

L'utente può revocare l'autorizzazione nelle impostazioni di sicurezza del
proprio account Google e può eliminare i file di backup dal proprio Drive.
Revocare l'accesso interrompe i futuri trasferimenti, ma non elimina le copie
già presenti. Le copie locali precedenti restano sul rispettivo computer fino
a una pulizia esplicita. La perdita della chiave impedisce di decifrare i backup.

L'utilizzo delle informazioni ricevute dalle API Google rispetta le
[Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy),
compresi i requisiti di uso limitato. Per richieste riguardanti questa utilità
personale, il contatto è l'email di assistenza indicata nella schermata di
consenso Google dell'app.
